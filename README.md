# ADDRESS

Бесконечное исследование лиминальных пространств: Backrooms, Poolrooms, Frutiger Aero. Unity 6 (URP).
Каждое место — это адрес в бесконечной Библиотеке; уровни генерируются детерминированно, выходы нужно замечать.

- Движок: Unity 6000.4 (URP 17), проект в `Game/`
- Инструменты (Blender-модели, текстуры, звуки, загрузка CC0-ассетов): `Tools/`
- Дизайн и журнал разработки: `Docs/GDD.md`, `Docs/PROGRESS.md`
- Готовая сборка для Windows — в Releases.

Ассеты: собственные модели (Blender) и CC0 (Poly Haven, ambientCG). Шрифты: Russo One, IBM Plex Mono (OFL).
Браузер внутри игры: UnityWebBrowser (MIT, Chromium/CEF).
